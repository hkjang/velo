Agent Protocol Ecosystem

5개 표준 Agent Protocol 통합 지원

에이전트 생태계의 모든 표준 통신 스펙을 단일 서버 게이트웨이에서 서비스합니다.

Google Agent-to-Agent (A2A) Protocol

Google의 에이전트 간 JSON-RPC 2.0 협업 표준 스펙. /ai-platform/a2a 엔드포인트에서 tasks/send, message/send, /.well-known/agent.json 에이전트 카드 검색 지원. 

curl -X POST http://localhost:8080/ai-platform/a2a \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "tasks/send",
    "params": {
      "message": {
        "role": "user",
        "parts": [{"type": "text", "text": "데이터 분석 태스크 수행 요청"}]
      },
      "capability": "data-analytics"
    },
    "id": 1
  }'

Agent Communication Protocol (ACP)

비동기 에이전트 태스크 생성, 상태 머신 관리, 멀티모달 파일 입출력을 지원하는 에이전트 스펙. /ai-platform/acp/* 엔드포인트. 

curl -X POST http://localhost:8080/ai-platform/acp/runs \
  -H "Content-Type: application/json" \
  -d '{
    "agent_id": "translator-agent-v1",
    "input": "Velo WAS documentation translation",
    "mode": "async"
  }'

Agent Gateway Protocol (AGP)

수백 개의 에이전트 서비스를 중앙에서 등록, 상태 동기화, 지능형 헬스체크 및 라우팅을 수행하는 중앙 오케스트레이터 허브. /ai-platform/agp/admin/*. 

curl -X GET http://localhost:8080/ai-platform/agp/admin/agents \
  -H "Authorization: Bearer velo-admin-key"

Model Context Protocol (MCP)

Anthropic 표준 에이전트 도구(Tools), 프롬프트(Prompts), 데이터 리소스(Resources)를 JSON-RPC 2.0 및 SSE 스트리밍으로 노출하는 서버/게이트웨이. /ai-platform/mcp. 

curl -X POST http://localhost:8080/ai-platform/mcp \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "tools/list",
    "id": 1
  }'

OpenAI Compatible Proxy (/v1/chat/completions)

OpenAI Python / Node.js SDK와 100% 드롭인 호환되는 게이트웨이 API. 기존 코드 수정 없이 Velo WAS 주소로 base_url 설정 시 자동 연동. 

from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8080/ai-platform/v1",
    api_key="velo-demo-key"
)

response = client.chat.completions.create(
    model="llm-general",
    messages=[{"role": "user", "content": "Velo WAS 멀티 LLM 연동 테스트"}]
)

print(response.choices[0].message.content)

Quick Start

단 1개 명령어 실행으로 바로 시작

의존성 패키지 설치 없이 단일 Fat JAR (9.6MB) 실행만으로 모든 서비스가 준비됩니다. 

# Step initialization
java -jar was-bootstrap-0.6.15-jar-with-dependencies.jar

# Step initialization
curl -X POST http://localhost:8080/ai-platform/v1/chat/completions \
  -H "Authorization: Bearer velo-demo-key" \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"Hello Velo WAS!"}]}'

# Step initialization
curl http://localhost:8080/ai-platform/.well-known/agent.json

# Step initialization
open http://localhost:8080/ai-platform

FAQ & AEO

Frequently Asked Questions

Velo WAS 플랫폼 도입에 대한 궁금증을 확인해 보세요.

Velo WAS란 무엇이며 기존 WAS(Tomcat/JEUS)와 어떻게 다른가요?
Velo WAS는 Netty 기반 Java 21 엔터프라이즈 서블릿 호환 WAS에 멀티 LLM 게이트웨이와 AI 에이전트 통신 허브를 결합한 AI-Native 애플리케이션 서버입니다. 기존 Tomcat이나 JEUS 대비 HTTP/2 및 비동기 I/O 성능이 뛰어나며, 서블릿 웹 앱 구동과 동시에 AI 모델 추론과 에이전트 오케스트레이션을 단일 서버 프로세스로 처리할 수 있습니다.
어떤 AI 프로바이더와 멀티모달 기능을 지원하나요?
OpenAI (GPT-4o), Anthropic (Claude 3.5), vLLM, SGLang, Ollama 등 주요 AI 프로바이더를 지원하며, 텍스트 대화, Vision(이미지 분석), Image Gen(DALL-E), STT(Whisper 음성인식), TTS(음성 합성), Vector Embedding 등 6대 멀티모달 기능을 모두 지원합니다.
A2A, ACP, AGP, MCP 프로토콜이란 무엇인가요?
A2A(Agent-to-Agent)는 Google의 에이전트 간 JSON-RPC 2.0 협업 프로토콜, ACP(Agent Communication Protocol)는 태스크 기반 비동기 에이전트 통신, AGP(Agent Gateway Protocol)는 에이전트 등록/발견/라우팅 중앙 허브, MCP(Model Context Protocol)는 에이전트 도구 및 리소스 연결 프로토콜입니다. Velo WAS는 이 5개 표준 프로토콜을 단일 게이트웨이에서 오케스트레이션합니다.
기존 Python / Node.js OpenAI SDK 클라이언트와 호환되나요?
네, 완전 호환됩니다. /ai-platform/v1/chat/completions 엔드포인트를 제공하므로, 기존 OpenAI SDK 클라이언트의 base_url을 Velo WAS 주소로 지정하면 코드 변경 없이 의도 기반 라우팅, 실시간 감사 로깅, 과금 미터링 기능을 즉시 활용할 수 있습니다.
Velo WAS 도입 상담 및 프로젝트 문의는 어떻게 하나요?
Velo WAS 관련 프로젝트 문의, 기술 지원, 엔터프라이즈 컨설팅은 공식 이메일 gagagiga@naver.com 으로 메일을 보내주시면 IT 전문 엔지니어가 신속하게 상담 및 가이드를 제공해 드립니다.
